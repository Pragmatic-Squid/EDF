# Everon Defense Force

This is a project that aims to add a new faction to ArmA: Armed Assault: the Everon Defense Force, or EDF for short.

The EDF will have:
- Three military branches:
  - Territorial Defense: An older branch equipped with mostly soviet era gear
  - Modern Army: A modernized branch equipped with more modern weapons and gear, leaning more toward western armaments
  - Special Forces: A banch for special operations with the most modern equipment, leaning heavily towards western armaments
- Each branch will have its own camouflage and equipment

The mod will be build on vanilla ArmA fist and later be added with support for ACE.
