# Everon Defense Force

This is a project that aims to add a new faction to ArmA: Armed Assault: the Everon Defense Force, or EDF for short.

The EDF will have:
- Three military branches:
  - Territorial Defense Forces (TDF): Mostly consisting of reservists and a few soldiers from the Regular Forces
  - Regular Forces (RF): A modernized branch equipped with more modern weapons and gear, leaning more toward western armaments
  - Special Operations Forces (SOF): A banch for special operations with the most modern equipment, leaning heavily towards western armaments
- Each branch will have its own camouflage and equipment

The mod will be build on vanilla ArmA fist and later be added with support for ACE.
